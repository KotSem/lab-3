## 1. Назначение и описание плагина

**Block Generator** — расширение для среды разработки Visual Studio Code, предназначенное для быстрой и наглядной генерации базовых управляющих конструкций:
- Условных операторов (`if`)
- Циклов со счётчиком (`for`)
- Циклов с предусловием (`while`)

Плагин автоматически определяет язык открытого файла (Python, C/C++ или JavaScript) и формирует синтаксически корректный код с учётом синтаксиса выбранного языка.

---

## 2. Короткое техническое задание (ТЗ)

1. **Цель проекта:** Автоматизировать вставку типовых управляющих конструкций с автоматической адаптацией под язык (Python / C / C++ / JavaScript).
2. **Среда разработки:** Visual Studio Code (Extension API).
3. **Поддерживаемые языки:** Python, C, C++, JavaScript.
4. **Способ вызова:**
   - Контекстное меню редактора (клик правой кнопкой мыши -> «Вставить блок»).
   - Палитра команд `Ctrl+Shift+P`.
5. **Входные данные:**
   - Выбор конструкции из выпадающего списка (`if`, `for`, `while`).
   - Ввод параметров (переменная, количество итераций или условие).
6. **Выходные данные:**
   - Сгенерированный блок кода, вставленный на позиции курсора.
7. **Компактность и прозрачность:**
   - Полная реализация логики всего в ~55 строк кода без избыточных зависимостей для простоты защиты работы.

## 3. Архитектура и структуры данных

### Архитектура работы плагина

```
[Пользователь]
      │
      ├─ 1. Клик правой кнопкой мыши в редакторе
      ▼
[Выпадающее меню]
      │
      ├─ 2. Выбор конструкции (if, for, while)
      ▼
[Вставка кода] ──> Блок вставляется в открытый файл
```

### Структура данных `TEMPLATES`
Вся логика синтаксиса оформлена в виде словаря текстовых шаблонов:

```javascript
const TEMPLATES = {
    python: {
        if: "if {CONDITION}:\n    pass",
        for: "for {VAR} in range({COUNT}):\n    pass",
        while: "while {CONDITION}:\n    pass"
    },
    c: {
        if: "if ({CONDITION}) {\n    // код\n}",
        for: "for (int {VAR} = 0; {VAR} < {COUNT}; {VAR}++) {\n    // код\n}",
        while: "while ({CONDITION}) {\n    // код\n}"
    },
    javascript: {
        if: "if ({CONDITION}) {\n    // код\n}",
        for: "for (let {VAR} = 0; {VAR} < {COUNT}; {VAR}++) {\n    // код\n}",
        while: "while ({CONDITION}) {\n    // код\n}"
    }
};
```

## 4. Инструкция по проверке и запуску

Плагин установлен непосредственно в расширения VS Code (`~/.vscode/extensions/kotsem.block-generator-1.0.0`).

### Проверка работы:
1. Откройте любой файл Python (`.py`), C/C++ (`.c`) или JavaScript (`.js`) в VS Code.
2. Кликните правой кнопкой мыши в любом месте файла.
3. Выберите пункт **«Block Generator: Вставить блок»** (или нажмите `Ctrl+Shift+P` и начните вводить это название).
4. Выберите тип блока (`if`, `for`, `while`), введите параметры и нажмите Enter.
5. Блок кода появится в редакторе в позиции курсора!
